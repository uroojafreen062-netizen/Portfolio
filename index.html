A focused plan to build the foundations for a future in bioinformatics. These are learning goals, not completed qualifications.

Month 1

Strengthen Python

Practise variables, conditions, loops, functions and small problem-solving exercises.

Month 2

Python practice

Work with lists, dictionaries, files and beginner coding tasks.

Month 3

NumPy fundamentals

Learn arrays, indexing and basic numerical operations.

Month 4

Pandas and data handling

Practise reading, cleaning, filtering and summarising simple datasets.

Visualisation and statistics

Learn introductory plots and descriptive statistics; explain what a dataset shows.

Introductory bioinformatics

Explore public biological databases and basic sequence concepts; plan a beginner project.
